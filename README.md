# Джарвис — репетитор по математике (5 класс)

Веб-приложение «Джарвис» — персональный репетитор по математике для ученика 5 класса (программа РФ). Работает полностью офлайн в браузере, без сервера и аккаунтов.

## Возможности

- **Диагностика по всей программе** — 26 заданий по 13 темам 5 класса: натуральные числа, порядок действий, площадь и объём, обыкновенные и десятичные дроби, проценты, уравнения, текстовые задачи.
- **Карта знаний** — каждая тема получает статус: «Уязвимость», «Требует доработки» или «Прочная броня».
- **Теория простым языком** — правила, разобранные примеры и советы по каждой теме.
- **Тренажёр с анализом ошибок** — бесконечная генерация заданий; приложение распознаёт типичные ошибки (перевёрнутая дробь, сложенные знаменатели, неверный порядок действий, съехавшая запятая и т. д.) и объясняет, в чём именно проблема, с пошаговым решением.
- **Прогресс** — серии верных ответов повышают уровень темы; статистика и типичные ошибки сохраняются в `localStorage`.

## Стек

React 19 · TypeScript · Vite · Tailwind CSS · lucide-react

## Запуск

```bash
npm install
npm run dev      # dev-сервер
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

```
src/
  data/        # темы, теория и генераторы заданий с детекторами ошибок
  lib/         # типы, математические утилиты, движок прогресса
  components/  # QuizCard (проверка ответов), карточки тем, «реактор» Джарвиса
  screens/     # главная, диагностика, экран темы (теория + тренажёр)
```
